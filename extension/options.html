doclab

Quick notes & screenshots into a fixed Downloads subfolder.

Slashes allowed for nested folders, e.g. notes/web.
Shortcuts (change them at chrome://extensions/shortcuts):
Alt+Shift+N — open quick note overlay
Alt+Shift+P — save screenshot of the visible tab

Silent saves: disable "Ask where to save each file before downloading" in your browser's download settings, otherwise each save opens a dialog.

Limitation: browsers only allow writes inside the Downloads folder (or a subfolder of it). An arbitrary absolute path is not possible.
